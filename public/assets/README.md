# Asset intake

No artwork, models, sprite sheets, or sticker binaries are included in this starter.

Before adding an asset, record its origin, creator/rights holder, permission or license, attribution, source-game/version where relevant, format, dimensions/polycount where relevant, and file size. Public availability alone does not establish redistribution permission.

Resolve D3 in [decisions](../../docs/decisions.md) for approved formats, compression, and Git/large-file/external delivery. Keep original source assets separate from generated runtime derivatives once that workflow is chosen.

For Pokémon display models, retain the first-Switch-appearance rule and its provenance. For stock stickers, replace repeated prototype placeholders with an identified catalog. User uploads are user data; their validation, storage, and deletion need D8 before implementation.

Seiko and her personalized Chingling are optional sample-profile content. Do not treat that appearance as the standard Chingling asset.
